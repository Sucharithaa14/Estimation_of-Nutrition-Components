# Estimation of Nutrition Components

Academic project — Django web app that estimates calories, protein, and fat content of food items using a relational database and dynamic template rendering.

## Tech Stack
Python · Django · MySQL · HTML5 · CSS3 · JavaScript

## How to Run
```bash
pip install django pymysql pandas numpy scikit-learn cryptography
python manage.py runserver
```
Visit `http://127.0.0.1:8000`
